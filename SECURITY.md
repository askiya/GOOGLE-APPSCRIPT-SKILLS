# Security policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Report a vulnerability

Do not open a public issue for a vulnerability that exposes credentials, private Google Workspace data, authorization bypasses, or an actively exploitable deployment. Contact the maintainer privately through the repository owner's GitHub profile and include:

- affected skill or file;
- impact and realistic attack scenario;
- safe reproduction steps;
- suggested mitigation, if known.

Never include live OAuth tokens, Script IDs, deployment URLs containing sensitive query data, account identifiers, or production records. Replace them with synthetic values.

## Scope

The repository primarily contains instructions and templates. Users remain responsible for reviewing generated code, requested OAuth scopes, deployment identity, sharing settings, quotas, data retention, and Google Workspace policies before production use.
