# Support

Use GitHub Discussions for usage questions and ideas. Use GitHub Issues for reproducible defects in a skill, validator, installer, or documentation.

Before opening an issue:

1. Run `npm test` and include its output.
2. Identify the skill and exact prompt used.
3. Remove Script IDs, credentials, deployment URLs, and personal data.
4. State your Apps Script project type: standalone, container-bound, web app, add-on, or API executable.
5. Explain the expected and actual result.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
