# Third-party research notices

This repository may study third-party projects to improve original Apps Script guidance. Unless a specific notice says otherwise, third-party source code, media, fonts, and component assets are not bundled.

## Impeccable

The Apps Script UI craft, hardening, surface-mode, and bounded-QA guidance was independently written after studying [Impeccable](https://github.com/pbakaus/impeccable), an Apache-2.0 project by Peter Bakaus and contributors.

- Upstream: <https://github.com/pbakaus/impeccable>
- License: <https://github.com/pbakaus/impeccable/blob/main/LICENSE>
- Material included: concepts and research attribution only; no upstream scripts, detector implementation, command files, or assets.

## UI component research

Magic UI, SyntaxUI, Lenis, Svelte Animations, React Bits, and demonstration repositories may be used as attributed research references. No code or assets from those projects are included by this change. Each future incorporation must pass the license, compatibility, security, and attribution gate in `apps-script-design-research`.

React Bits source is specifically excluded from redistribution or porting because the inspected license restricts distributing the components themselves or ported versions. Repositories without a clear license are treated as reference-only.
