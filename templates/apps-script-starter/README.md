# Apps Script starter

Copy these files into a new clasp project as a deliberately small HTML Service baseline.

Before production use:

1. Set the intended time zone.
2. Add only the OAuth scopes actually required.
3. Replace the sample facade with server-side authentication and authorization appropriate to the deployment.
4. Add domain services and repository adapters rather than growing `Code.gs` indefinitely.
5. Add tests, a test deployment, and representative-role smoke checks.
6. Review secrets, logging, quotas, and failure recovery.

This template is an example, not a complete security or application architecture.
